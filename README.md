## 📌 Overview
**DevVault** is a modern, lightweight developer directory and resource-sharing platform. It allows engineers, designers, and students to discover, search, upvote, and contribute top developer tools, documentation, APIs, and frameworks.

---

## ✨ Features
- ⚡ **Instant Search**: Real-time filtering by resource title and description.
- 🎯 **Category Filtering**: Explore tools across **Web Dev**, **App Dev**, **AI/ML**, and **Dev Tools**.
- 👍 **Interactive Voting**: Upvote community resources with local storage duplicate vote prevention.
- ➕ **Resource Contribution**: Add custom developer tools with instant local persistence.
- 🌙 / ☀️ **Dark & Light Mode**: Seamless theme switching with saved preference.
- 🎨 **Cyber-Modern Aesthetic**: Glassmorphism, smooth micro-animations, and responsive layout.

---

## 🛠️ Tech Stack
- **HTML5**: Semantic and clean structure
- **CSS3**: Custom design system, CSS variables, flexbox & grid
- **JavaScript (ES6)**: Dynamic DOM manipulation, array filtering, and LocalStorage API
- **Deployment**: [Vercel](https://vercel.com)

## 💻 Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aashutoshrajput43-aiml/devvault-hub.git
   cd devvault-hub
   ```

2. **Open directly in browser**:
   - Double click `index.html` to open it in your browser.

3. **Or run with a local server**:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node.js
   npx serve .
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
